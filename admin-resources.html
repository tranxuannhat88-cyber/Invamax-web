Cài đặt Tự động Đăng lên Website (GitHub Sync)

Khi kết nối GitHub Token, mỗi lần bạn thêm hoặc sửa tài liệu ở trang Admin, hệ thống sẽ tự động commit và đẩy dữ liệu lên kho GitHub của Invamax. Nhờ đó, tất cả máy tính và khách hàng sẽ thấy nội dung mới ngay lập tức mà không cần thao tác code!

📖 Hướng dẫn lấy mã GitHub Token (chỉ mất 30 giây):
  1. Đăng nhập tài khoản GitHub tranxuannhat88-cyber.
  2. Truy cập trực tiếp liên kết: github.com/settings/tokens (mục Tokens classic).
  3. Bấm nút Generate new token (classic).
  4. Ở ô Note, nhập: Invamax Admin Auto Sync.
  5. Ở mục Select scopes, tick chọn ô vuông repo (Full control of private repositories).
  6. Cuộn xuống dưới cùng bấm Generate token, sao chép chuỗi ký tự hiển thị (dạng ghp_...) rồi dán vào ô bên trên.
Thao tác thành công!
